## Quick Design Tips

1. **Keep it simple** - One main message per graphic
2. **Use white space** - Don't crowd the design
3. **High contrast** - Text should be easily readable
4. **Brand colors** - Stick to your color palette
5. **Consistent fonts** - Use 2-3 fonts max
6. **Mobile-first** - Design for small screens first
7. **Test on devices** - Check on phone before posting

---

## Export Checklist

Before exporting:
- [ ] Spell check all text
- [ ] Verify brand colors
- [ ] Check contrast ratio
- [ ] Test at actual size
- [ ] Ensure file size < 500KB
- [ ] Include alt text concepts
- [ ] Name files appropriately

Export settings:
- Format: PNG (for graphics)
- Quality: High (72 DPI for web)
- Transparent: No (unless needed)
