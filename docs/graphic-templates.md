# Social Media Graphic Templates
## For adrienbird.net Blog Promotion

These templates are designed for Canva but work in any design tool (Figma, Photoshop, etc.).

---

## Template 1: Blog Announcement (LinkedIn/Instagram)

**Size:** 1080x1080px (Square)

**Layout:**
```
┌─────────────────────────────────────┐
│                                     │
│    🚀 NEW BLOG POST                  │
│                                     │
│    [TITLE - 3 lines max]             │
│    [48pt bold, #1a1a1a]              │
│                                     │
│    ───────────────────────────────  │
│                                     │
│    [Key insight - 2 lines]           │
│    [24pt regular, #666]              │
│                                     │
│    [3 bullet points]                 │
│    ✓ [Point 1]                       │
│    ✓ [Point 2]                       │
│    ✓ [Point 3]                       │
│                                     │
│    ───────────────────────────────  │
│                                     │
│    Read more:                       │
│    adrienbird.net/blog              │
│                                     │
│    [#hashtags]                       │
│                                     │
└─────────────────────────────────────┘
```

**Color Palette:**
- Background: #ffffff or #f8f9fa
- Primary: #1a1a1a (text)
- Accent: #0066cc (links/CTA)
- Secondary: #666666 (subtext)
- Highlight: #e8f4ff (backgrounds)

**Fonts:**
- Headlines: Inter Bold, 48pt
- Subheadlines: Inter SemiBold, 24pt
- Body: Inter Regular, 18pt
- URL: Inter Medium, 16pt

## Brand Guidelines

### Colors
```css
/* Primary */
--primary: #1a1a1a;       /* Black/Dark Gray */
--accent: #0066cc;        /* Blue */
--accent-light: #e8f4ff;  /* Light Blue */

/* Secondary */
--text: #1a1a1a;          /* Main text */
--text-light: #666666;    /* Secondary text */
--bg: #ffffff;            /* White background */
--bg-alt: #f8f9fa;        /* Light gray background */

/* Category Colors */
--security: #00c853;      /* Green */
--go: #00add8;            /* Cyan */
--cloud: #ff6d00;         /* Orange */
--growth: #aa00ff;        /* Purple */
--data: #ff1744;          /* Red */
```

### Typography
```css
/* Font Family */
font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;

/* Sizes */
--h1: 48px;   /* Main headline */
--h2: 36px;   /* Subheadline */
--h3: 24px;   /* Section headers */
--body: 18px; /* Body text */
--small: 16px;/* Captions, URLs */

/* Weights */
--bold: 700;
--semibold: 600;
--medium: 500;
--regular: 400;
```

### Icon Style
- Use simple line icons
- 2px stroke width
- Rounded corners (4px radius)
- Color: #1a1a1a or accent color

## Quick Export Settings

### Canva Export
- **Format:** PNG
- **Quality:** High (300 DPI for print, 72 DPI for web)
- **Transparent background:** No (use white or brand colors)

### File Naming
```
[platform]-[topic]-[date].png

Examples:
- linkedin-agent-swarms-2026-04-02.png
- twitter-go-profiling-2026-04-03.png
- youtube-thumb-youtube-algorithm-2026-04-03.png
```

## Batch Creation Workflow

1. **Morning (30 min):** Create 3-5 graphics for the day
2. **Afternoon (15 min):** Review and schedule
3. **Evening (15 min):** Engage with comments

**Weekly batch:**
- Sunday: Create all graphics for the week
- Use Canva Pro's bulk features
- Organize by platform in folders

## Analytics Integration

Track which graphics perform best:
- Click-through rate
- Engagement rate
- Shares/saves
- Follower growth

**Optimize based on data:**
- Top 3 designs → use more
- Bottom 3 designs → retire or iterate
- Test colors, fonts, layouts
